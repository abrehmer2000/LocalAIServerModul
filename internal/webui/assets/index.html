Agent mit der Zentrale verbinden

Erstelle eine einmalige Verbindungsdatei und öffne sie im Agent-Assistenten auf dem gewünschten Rechner. Dort werden Laufzeit und Verbindung geprüft.

Verbindungsdatei herunterladen

Die Datei ist zehn Minuten gültig und enthält einen vertraulichen Anmeldecode. Bei Ablauf hier eine neue Datei erstellen.

Auf Agent warten

Öffne die Verbindungsdatei im Agent-Assistenten. Diese Ansicht aktualisiert sich automatisch.

Der Auftrag lädt das ausgewählte Modell auf diesen Server und startet dessen Modellprozess. Andere Server werden nicht verändert.

Antwort auf diesem Server prüfen

Der Test spricht genau den neuen Server an und prüft, ob eine vollständige Textantwort ankommt.

Noch keine verwalteten Server.

Sichern und später fortsetzen

Vor dem Abschalten kurzlebiger Cloud-Server die Zentrale und jeden Agenten sichern. Die Archive enthalten vertrauliche Schlüssel. Modelldateien werden nicht mitgesichert.

Was wird gesichert?

Konfiguration, Zertifikate und eine konsistente Datenbankkopie mit Audit-Verlauf. Die Agent-Identität wird im jeweiligen Agent-Assistenten gesichert. Das Abschalten erfolgt beim Anbieter; mögliche Speicherkosten dort prüfen.

Audit-Trail

Metadaten zu Anfragen und Verwaltungsaktionen. Keine Prompts oder Modellantworten. Die letzten 100 Einträge werden angezeigt.
