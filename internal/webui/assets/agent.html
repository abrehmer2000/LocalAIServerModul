Die Einstellungen gelten für den Rechner, auf dem dieser Agent läuft.

Wo möchtest du einen Rechner einrichten?

Für Cloud-Anbieter und On-Premises-Server. Dieser Assistent läuft auf dem Rechner des Agent-Programms, nicht zwingend auf dem Rechner deines Browsers.

Linux-Server über SSH verbinden

  1. 1 · Zugang
  2. 2 · Identität prüfen
  3. 3 · Installieren

Die Zentrale muss vom Zielserver über HTTPS oder VPN erreichbar sein. Bestehende SSH-Zugänge und ein entsperrter Schlüssel werden verwendet. Es werden keine Cloud-Zugangsdaten benötigt.

SSH-Schlüssel auswählen

Private Schlüssel werden nicht auf den Zielserver kopiert. Verschlüsselte Schlüssel müssen im SSH-Agenten des Betriebssystems entsperrt sein.

Ist das der richtige Server?

Vergleiche den Fingerabdruck mit der Serverkonsole oder deiner Administration. 


            
          

          

            
Installation vorbereiten

            

              
              
              
              

                Leer lassen, wenn eine passende Laufzeit auf dem Zielserver
                vorhanden ist. Das Paket muss zur Architektur und den Treibern
                des Zielservers passen.
              

              
              

                Diese Änderungen werden vorgenommen
                

                  Agent und optional Laufzeit im Benutzerverzeichnis
                  installieren, mit der Zentrale anmelden und im Hintergrund
                  starten. Bestehende Agent-Identitäten werden nicht
                  überschrieben. Es werden keine Server gemietet und keine
                  Treiber oder Firewallregeln geändert. Ein Systemdienst wird
                  nur auf ausdrücklichen Wunsch und bei vorhandener
                  Unterstützung eingerichtet. Andernfalls läuft der Agent im
                  Hintergrund; die Abschlussmeldung nennt den tatsächlichen
                  Startmodus.
                

              

            

            

              
              
              

                Der Manager öffnet ausschließlich lokale SSH-Tunnel und
                verbindet sie bei Unterbrechungen erneut. Er merkt sich die
                Verbindung auf diesem Rechner. Keine Programme oder Schlüssel
                werden auf den Server kopiert. Der Manager muss geöffnet
                bleiben.

        Zentrale öffnen ↗
        

          Der Manager hält die Verbindung im Hintergrund. Bei unterbrochener
          Verbindung kurz warten oder den SSH-Schlüssel entsperren.

Verbindung zur Zentrale auswählen

            

              Wähle die Verbindungsdatei, die du in deiner Zentrale unter
              „Server hinzufügen“ erstellt hast.
            

            
            

            

              
                Bestehenden Agenten aus einer Sicherung wiederherstellen
              
              

                Nur nach Abschalten der bisherigen Instanz verwenden. Dieselbe
                Agent-Identität darf nicht auf zwei laufenden Rechnern verwendet
                werden.
              

              
              

            

          

          

            
Modell-Laufzeit vorbereiten

            

              Eine vorhandene llama.cpp-Laufzeit wird automatisch gesucht. Du
              kannst auch ein passendes Laufzeitpaket importieren.
            

            
            

              Nur Pakete aus einer vertrauenswürdigen Quelle verwenden, passend
              zu Betriebssystem, Prozessor und GPU-Treibern. Das Paket enthält
              ausführbare Programme. Treiber werden nicht verändert.
            

            
            

            

              Erweiterte Einstellungen
              
              
              
              

                Eine vorhandene Datei wird vor dem Start gegen die
                Modell-Prüfsumme geprüft und ohne zweite Kopie verwendet.
              

              
            

          

          

            
Rechner und Verbindung prüfen

            

              Die Anmeldung erfolgt erst im nächsten Schritt. Diese Prüfung
              verbraucht den Anmeldecode nicht.
            

            
    
            
          
    
          
    
            
    Mit der Zentrale verbinden
    
            
    
            
    
              Der Agent erhält eine eigene Identität und verbindet sich
              ausgehend mit der Zentrale. Das Modell wird anschließend im
              zentralen Assistenten eingerichtet.
            
    
            
          
    
          
    
            
    Rechner ist angemeldet
    
            
    
            
    
              Wechsle zur Zentrale zurück. Dort geht es mit Modelldownload,
              Start und einer echten Testantwort weiter. Dieser Agent muss dafür
              laufen.
            
    
            
          
    
          
    
          
          
    
            
          
    
        
    
      
    
      
    
        
    Betrieb und Sicherung
    
        
    
          Automatischen Start bei Benutzeranmeldung einrichten. Für
          unbeaufsichtigte Server ist ein Systemdienst erforderlich.
        
    
        
        
    
        
        
    
          Die Sicherung enthält vertrauliche Zugangsdaten, keine Modelle oder
          Laufzeitdateien. Vor dem Abschalten von kurzlebigen Servern
          herunterladen und geschützt aufbewahren.
